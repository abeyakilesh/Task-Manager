# Task Manager

A simple and clean **Task Manager application** built using **HTML, CSS, and Vanilla JavaScript**.  
This project focuses on core front-end fundamentals such as state management, DOM manipulation, and clean code structure — without the use of heavy frameworks.

---

## Features

- **Add tasks**: Quickly add new items to your list.
- **Toggle Completion**: Mark tasks as done with a single click.
- **Delete tasks**: Remove tasks instantly from the UI.
- **Keyboard Support**: Full support for the `Enter` key to submit tasks.
- **Empty State**: Friendly messaging when the list is empty.
- **Reactive UI**: Updates the DOM dynamically without page reloads.

---

## Tech Stack

- **HTML5** – Semantic application structure.
- **CSS3** – Layout styling using **Flexbox** for responsiveness.
- **JavaScript (ES6+)** – Application logic and DOM manipulation.
- **Git & GitHub** – Version control and project hosting.

# What I Learned
State Management: Handling data flow within a vanilla environment.

Array Methods: Practical application of .map() for rendering and .filter() for deletion.

Immutability: Understanding why and how to update data without mutating the original state.

DOM Updates: Creating and injecting elements dynamically based on user input.

Clean Code: Maintaining a strict separation of concerns between structure, style, and logic.
